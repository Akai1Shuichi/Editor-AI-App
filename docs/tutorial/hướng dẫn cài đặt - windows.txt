* Đối với Windows 10 trở xuống, thông thường bạn có thể cài đặt và mở EditorVideoApp như bình thường.

* Đối với Windows 11, Smart App Control có thể cảnh báo app bên thứ 3.

Để tắt Smart App Control:

Start → Privacy & Security → App & browser control → Smart App Control settings → Off

Sau khi tắt, hãy mở lại EditorVideoApp.
